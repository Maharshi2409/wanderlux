# WanderLux Travel Agency – ICT502 Assessment 2

Static website built with semantic HTML5, CSS3 and vanilla JavaScript.

## Pages
- `index.html` – Home (rotating banner, popular packages)
- `destinations.html` – Destinations & Services (with filter)
- `calculator.html` – Trip Cost Calculator
- `appointment.html` – Appointment Request form (emails via FormSubmit)
- `about.html` – About Us
- `contact.html` – Contact details, map and contact form

## Email set-up
Open `js/forms.js` and set `AGENCY_EMAIL` to your inbox. Submit the form once on the
live site and click the activation link FormSubmit emails you.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.
